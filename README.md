# Splunk-Security-Alerting
 Creating Splunk Alert  To Detect Failed Login Attempt On A Windows Server

 This project showcases the implementation of Splunk-based security alerting, where log data from endpoints and network devices can be ingested, correlated, and analyzed to generate actionable alerts for potential security incidents.

This project is also inline with the NIST Cybersecurity Framework (CSF):
 
 Detect function(DE.CM – Security Continuous Monitoring) Continuous monitoring of logs and events using Splunk, and also(DE.AE – Anomalies and Events) Identifying and analyzing unusual activity through alerting rules.

 Respond function(RS.AN – Analysis) Supporting incident response by providing timely alerts for investigation.

 
 Also inline with the the international standard ISO/IEC27001 Annex A:
 Annex A.8 (Technological Controls):
 A.8.16 Monitoring Activities – monitoring system activities and logs.
 Annex A.5 (Organizational Controls) Supporting governance through defined monitoring and alerting policies.
